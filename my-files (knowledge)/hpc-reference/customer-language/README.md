## How it's made

The `/customer-language` skill (`my-skills/customer-language/instructions.md`) makes these files. Scout runs it once a month and ROUX sets the schedule. Each run adds a new `YYYY-MM-customer-language.md` and a new row in the table above, and moves the "Latest" link. Old files are never overwritten.

The older hand-written file, [../customer-language.md](../customer-language.md), still holds Evan's own objection answers (the Yeti frame, the two-part price answer) and the 2026-08-26 survey data. That file is for strategy. The monthly files are for verbatim lines.
