## Notes
- **Full-frame photos are what's missing.** Cutouts are already well covered.
- Higher resolution is better — 2000px+ on the long edge. Phone photos are fine.
- Bad lighting beats no photo. Send them and ROUX will work out what's usable.
- Tell ROUX roughly what each batch is; no need to name files carefully.
